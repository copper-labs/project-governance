# Delegated Research

Resolve one bounded uncertainty and return compact evidence to the coordinator.

## Trigger

Use only when launched with a `research-scout` worker brief.

## Required Reads

- The supplied compact worker brief
- Only the selected materialized context supplied beside the brief
- The installed role contract

## Workflow

1. Confirm the objective, snapshot, read scope, token budgets, and stop conditions.
2. Read only packet materialized refs. Do not call provider or graph tools; request expansion from
   the coordinator instead of recursively bootstrapping repository docs.
3. Resolve the assigned uncertainty without editing governed files or delegating again.
4. Return the shared result envelope without a transcript or repeated context.

## Validation

Cross-check material claims against the supplied sources and identify unresolved uncertainty.

## Evidence

Return concise findings, source or provenance refs, assumptions, confidence, and any requested context
expansion. Stay within the result budget.
