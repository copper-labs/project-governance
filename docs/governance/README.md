# Governance Index

- [Bootstrap standards](bootstrap-standards.md): exact wheel installation and target-owned files.
- [Release process](release-process.md): semantic versions and immutable wheel publication.
- [Validation strategy](validation-strategy.md): narrow proof and explicit broad boundaries.
- [Hook and check taxonomy](hook-and-check-taxonomy.md): thin hooks and runtime stages.
- [Context routing](context-routing.md): deterministic, repository-local context selection.
- [Context route guidance](context-routes.md): route configuration shape and route misses.
- [Writing style guide](writing-style-guide.md): durable documentation conventions.
- [Apple dependency policy](apple-dependency-policy.md): optional policy for repositories that adopt
  it.

These policies are generic. Product validation, terminology, source mappings, and tool commands
belong in the adopting repository.
