# Workspace context guidance

A native prompt in one checkout can coexist with an explicit task in another. The existing reader
correctly pauses hosted selection for the mismatched native entry, but its imperative attachment
message can be read as a blanket stop-work instruction. Clarify that separately authorized work
follows the verified explicit target's existing admission, using its runtime and binding where
required; host permissions, required guidance and disclosure limits always remain applicable. Preserve denied access, disclosure,
no retargeting and no sibling packet transfer. No new registry, hook, schema or recurring check.

One batch changes the notice, entry-error guidance, owning specification and both context and
checkout-transition guides. Validate the
rendered prompt contract and existing mismatch isolation tests together, then build and qualify the
exact archive. Text assertions verify delivered guidance, not model compliance or productivity.
