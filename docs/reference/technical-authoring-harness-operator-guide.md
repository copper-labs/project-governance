# Technical Authoring Operator Reference

Use the repository's own PRD, specification, plan, or guide template. State the reader, the
decision or behavior being recorded, the owner, and the verification boundary. Run the repository's
documentation pack when the document changes.

Use a reviewer for clarity, completeness, and terminology. Keep technical assertions traceable to
the source that owns them. If a document needs product language or required sections, put those
requirements in the adopting repository rather than the shared runtime.
