# Reference Index

This directory holds exact lookup material for reusable runtime surfaces when a distinct reference
job exists.

Reference docs should explain how to run a mechanism without becoming the policy source for that
mechanism. Reader-first authoring guidance remains in its specification and installed field guide;
it has no duplicate operator reference.
