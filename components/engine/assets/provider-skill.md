# Native {{provider}} delegation

Use provider `{{provider}}`. Before delegation, run the absolute repository-local
`.governance/runtime/bin/project-governance provider-help` and follow that installed guide for
binding, submission, observation, continuation, cancellation and recovery. It is the command authority
for this runtime; do not infer commands from an older installation.

Preserve the operator's exact model, effort, scope and restrictions. Supply explicit model and effort,
or the operator's explicit provider configuration. Do not silently substitute another provider,
model, text-only API or restricted tool mode. A review role describes the assignment, not a reduction
of native tools. Native authentication and configured connections remain provider-owned.

Delegate only work the parent authorized. Preserve the returned job directory and request digest;
observe that same job rather than resubmitting after a wait timeout. Tool access and assignment
constraints must be assessed from evidence. A provider completion is not parent acceptance or
publication authority. Missing tools, required user input and unconfirmed cleanup remain unresolved.

Desktop tools owned only by the parent are not implicitly available to a CLI worker. Keep the parent
responsible for those interactions, and do not fabricate tool availability or approve prompts silently.
