# Operate compiled provider jobs

Use the absolute repository-local `.governance/runtime/bin/project-governance provider-help` command
for the selected runtime's provider operations. The returned guide is the command authority for
submission, waiting, event cursors, continuation, cancellation, recovery and completion delivery.
Do not infer command aliases from the retired wheel helper.

Retain the job directory and request digest. Reconnect to that same job after interruption; do not
repeat an assignment because a wait expired or delivery failed. A queued completion is not parent
acceptance. Inspect execution results, input identity and cleanup before accepting work. Shared
workspace declarations coordinate participating jobs; they are not a filesystem sandbox.

For deterministic checks and device/build operations, read `skill-read --path test-execution/SKILL.md`.
Those operations use checks and authorized workflows, not a model assignment. Keep the parent's
native tools and required user interactions with the parent when a CLI worker cannot access them.
